Calculadora Funcional - JavaScript Nativo

Descripción
Este proyecto consiste en el desarrollo de una calculadora interactiva capaz de realizar operaciones aritméticas básicas. El objetivo principal fue fortalecer habilidades en lógica de programación, manejo de eventos en el DOM y diseño responsivo sin depender de librerías externas.

Tecnologías Utilizadas
- HTML5:Estructuración semántica de la interfaz.
- CSS3: Diseño visual, implementación de Flexbox/Grid y adaptabilidad (Responsive Design).
- JavaScript (ES6+): Lógica de procesamiento de datos, manejo de operadores y actualización dinámica de la interfaz.

Funcionalidades Clave
- Operaciones matemáticas: suma, resta, multiplicación y división.
- Manejo de decimales y limpieza de pantalla (AC/Delete).
- Interfaz intuitiva y adaptada a diferentes tamaños de pantalla.

Cómo visualizarlo
Puedes clonar este repositorio y abrir el archivo `index.html` en cualquier navegador moderno para probar su funcionamiento.
